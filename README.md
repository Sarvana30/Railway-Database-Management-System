# Railway Database Management System

A database management system for railway reservation and trip planning, developed as a course project.

## Project Status

🚧 **Currently under development**

## Technologies

* Python
* FastAPI
* MySQL
* SQLAlchemy

## Description

The project aims to provide functionality for railway ticket reservation and trip planning, including passenger and train management, booking and cancellation, and related database operations.

More features and improvements will be added as the project progresses.
